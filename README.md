# Axonris Video Studio

Free, open-source (MIT) video tool for [Axonris Hub](https://github.com/TegySLO/axonris-releases) users.

Two ways to make a video:
- **Generate from a description** — describe what you want, Claude Code (your own account) writes the script, voiceover, and visuals, and renders it.
- **Record a tutorial** — screen-record any app (including [Axonris Forge](https://github.com/TegySLO/axonris-forge-templates)), and get an auto-zoomed, dead-time-trimmed, polished result.

Free to install. Generation itself is BYOK (bring your own Claude Code + cloud GPU account) — see [Setup](#setup) below.

## Setup

Run the app once — the first-run wizard checks/guides you through Node.js, Python, FFmpeg, a Claude Code login, and a cloud GPU account (Modal has a free $30/month starter tier). Every step is skippable; you can install now and finish setup later.
